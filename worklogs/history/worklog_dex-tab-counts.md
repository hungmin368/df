# 圖鑑分頁標籤計數錯誤修復

- 日期：2026-10-17
- 任務 ID：dex-tab-counts

## 問題回報

開啟恐龍圖鑑時，三個分頁標籤應顯示「全部 140 / 常見 76 / 遠古王者 63」，實際上：

- 點「全部」：三個標籤都顯示 140
- 點「常見」：三個標籤都變成 76
- 點「遠古王者」：三個標籤都變成 63

## 根因

`js/main.js` 的 `updateDexTabs()` 呼叫 `dexPoolByTab()` 時，後者讀取的是全域 `dexTab`（目前選中的分頁），而不是各按鈕自己的 `data-t`。於是每次切換分頁，三個標籤都被渲染成「當前分頁」的數量。

## 修復步驟

1. 定位問題：`js/main.js:1535` `updateDexTabs()` 以全域 `dexTab` 計算所有按鈕的 pool。
2. 修改 `dexPoolByTab(t)`（`js/main.js:1530`）：改為接受分頁參數 `t`，未傳時退回全域 `dexTab`（維持既有呼叫端行為）。
3. `updateDexTabs()` 改以各按鈕的 `b.dataset.t` 呼叫 `dexPoolByTab(t)`，讓三個標籤各自顯示正確數量。
4. 資料確認：以 node 計算 `js/data.js`，DINOS=76、LEGENDS=63，加上伴伴共 140，與預期標籤一致。

## 驗證

1. 本機以 `python -m http.server 8765` 啟動伺服器，瀏覽器開啟 `http://127.0.0.1:8765/index.html`。
2. 開啟圖鑑，初始標籤：全部 140 / 常見 76 / 遠古王者 63 ✨（正確）。
3. 點「常見」：標籤維持 140/76/63，格子數 76，`dexfull-count` 顯示「收藏 0 / 76（全部 1 / 140）」。
4. 點「遠古王者」：標籤維持 140/76/63，格子數 63。
5. 點「全部」：標籤維持 140/76/63，格子數 140。
6. 截圖確認畫面正確。
