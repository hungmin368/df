- 限制條件：不嵌入遊戲、不提交/推送 git；所有產物放未追蹤目錄 `dino_assets/`，worklog 依 AGENTS.md 慣例建立但依使用者要求**不**提交。

## 執行步驟記錄

### 1. 盤點需求與環境檢查（完成）
- 確認 Python 3.13.14 + PIL 可用；無 Blender；`convert` 為 Windows 內建工具非 ImageMagick。
- 結論：本機無「文字生圖/3D 渲染」模型，PIL 只能做 2D 合成，無法憑空生成擬真 3D 恐龍圖。
- 建立輸出目錄 `dino_assets/`（新增，保持未追蹤，不動 .gitignore）。

### 2. 建立 200 種恐龍清單與稀有度評級（完成）
- 產出 `dino_assets/dinosaurs_200.json`：200 筆有效學名（獨立屬/種，無重複），欄位 id、name、zh、era、diet、rarity。
- 以 Python 驗證：筆數 200、id 1–200 連續、學名無重複、稀有度分布 5★=12、4★=40、3★=58、2★=52、1★=38。
- 產出人類可讀總表 `dino_assets/dinosaurs_200.md`（依星級分組，含評級標準說明）。
- 稀有度評級標準：綜合化石稀有度、科學地位、知名度/獨特性；5★ 傳說級（世界最頂尖象徵/化石極罕見/最大級），1★ 普及級（化石豐富的基礎小型物種）。

### 3. 產出 5 星名單與圖片生成規格（完成）
- 5★ 共 12 種：君王暴龍、埃及棘龍、南方巨獸龍、鯊齒龍、阿根廷龍、巴塔哥泰坦巨龍、無畏巨龍、海神龍、恐手龍、鐮刀龍、甲龍、始祖鳥。
- 產出 `dino_assets/prompts_5star.md`：統一風格規格（全身四分之三側面、去背 alpha PNG 1024×1024、博物館級 CGI 風格）＋ 每種解剖重點（防 AI 常見錯誤，如棘龍帆形、恐手龍鴨嘴與駝峰、鐮刀龍覆羽等）。

### 4. 嘗試生成 5 星圖片——受阻（完成，阻塞回報）
- 檢查本機文字生圖能力：無 SD/ComfyUI/Blender；PIL 無法生成擬真 3D 圖。
- 檢查環境變數：OPENAI/GEMINI/STABILITY/REPLICATE/HF 等 API 金鑰皆未設定。
- 結論：當時環境無法產出「去背 3D 真實圖」，回報使用者三個選項。

### 5. 改用免金鑰生圖服務並建立本機去背管線（完成）
- 測試 pollinations.ai（免金鑰，FLUX 模型）：複雜提示詞會產生怪獸化外型；改用極簡提示詞「{學名} dinosaur, full body, side view{特徵}, light gray background, no text」解剖最正確（以君王暴龍試驗 5 組提示詞比對）。
- 撰寫 `dino_assets/gen_images.py`：12 張 5★ 原圖下載（重試 3 次、3 秒間隔），輸出 `images/raw_*.jpg`。
- 去背先以「邊緣泛洪+容差」實作（`cutout.py`）：TOL=22 會穿透平滑腹部誤食主體；TOL=6 在多張圖仍滲漏（君王暴龍只剩 4.3%、南方巨獸龍失敗），判定不可靠。
- 改於 `dino_assets/.venv` 安裝 rembg（u2net 語意分割），重寫 `cutout.py`：rembg 去背 → 右下角浮水印小島清除 → 保留最大連通主體 → 內縮 1px 去光暈 → 裁切 3% 邊距 → 方形置中 → 1024×1024 RGBA PNG。

### 6. 完成 12 張去背圖並送使用者檢視（完成，未獲認可）
- rembg 預設模型下載達 1.02GB 且速度僅約 200kB/s（估 1.5 小時），改以顯式 `new_session("u2net")`（約 170MB）完成 12 張去背。
- 期間發現 `raw_01_Tyrannosaurus.jpg` 被先前的泛洪測試誤刪，補下載修復。
- 品質篩選：初版 12 張中無畏巨龍畸形、海神龍誤成雙足、棘龍缺帆；換種子/提示詞/turbo 模型重抽（海神龍、無畏巨龍改善為合格蜥腳類；棘龍換 5 次仍無帆，保留吻部最接近版）。
- 2026-09-24 使用者檢視 `preview_5star.png` 後表示「很醜不喜歡」——免費後端品質上限（解剖走樣、風格不統一）未被接受，管線雖通但產出不符需求。
- 已清理試驗暫存圖（`_test_*`、`_chk_*`、`_laplace_*`）；12 張 5star 草稿與原圖保留於 `images/` 待使用者決定去留。
