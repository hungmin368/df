恐龍快找 DragonFinder 隱私政策

生效日期：2026-10-18　·　適用版本：v1.9.17 及之後的所有版本

本隱私政策說明《恐龍快找 DragonFinder》（以下稱「本遊戲」）如何處理你的資料。本遊戲的設計原則是盡量少收集資料：不需帳號、不設伺服器、不嵌入分析或廣告 SDK。

一、我們不收集的資料

  • 不要求註冊帳號，不收集姓名、電子郵件、電話等身分資料。
  • 不嵌入任何第三方分析（Analytics）、廣告、追蹤 SDK。
  • 不收集裝置識別碼、精確位置、通訊錄、照片或其他裝置內容。

二、遊戲進度的保存方式

你的遊戲進度（分數、圖鑑、資源、設定等）只會儲存在你本人的裝置上（瀏覽器或 App 內部的本機儲存空間）。這些資料不會上傳到任何伺服器，開發者也無法讀取。刪除 App 或清除瀏覽器資料即會完全移除。

三、網路連線

本遊戲的核心玩法完全離線即可進行。首次開啟或更新後需要網路下載遊戲資源；若透過 GitHub Pages 遊玩網頁版，GitHub 會以標準方式記錄存取日誌（如 IP 位址），該記錄由 GitHub 依其隱私政策管理，非本遊戲所能控制。

四、兒童隱私

本遊戲不會故意收集任何未滿 13 歲（或你所在地法律規定的年齡）兒童的個人資料。由於我們不收集個人資料，自然不存在兒童資料外洩的風險。

五、你的權利

由於所有資料都保存在你的裝置上，你可以隨時透過刪除 App、清除瀏覽器快取，或遊戲內「工程模式 → 清存檔／重置遊戲」完整刪除一切資料，無需向我們提出申請。

六、政策變更

若未來更新引入會改變此政策的機能（例如雲端備份），我們會在更新前於此頁面與遊戲內明確公告。

七、聯絡方式

如對本政策有任何疑問，請透過 GitHub 專案頁面（https://github.com/hungmin368/df）與開發者聯絡。
