三、修正的焦點缺陷

缺陷說明修法
Enter 雙重觸發原生 uGUI Submit（Enter）與自訂 enterKey 處理各呼叫一次 HandleCell：標記被切兩次等於沒反應，捕捉會消耗兩個捕捉器移除自訂 Enter 處理，只留原生單一路徑
方向鍵雙重導覽原生自動導覽與自訂焦點追蹤同時反應方向鍵，焦點可能一次跳兩格移除自訂方向鍵處理；SyncFocusFromSelection 讓外框跟隨 EventSystem 選取
M 快捷鍵在選單無效M 只在遊戲內處理，與選單按鈕標示「音效：開 (M)」不符M 移到全域 HandleGlobalKeys
批次測試注入輸入無反應編輯器預設 PointersAndKeyboardsRespectGameViewFocus 在批次模式（遊戲視窗永遠無焦點）把鍵盤／觸控輸入導回編輯器，測試注入的事件被丟棄測試於 [UnitySetUp] 設定 editorInputBehaviorInPlayMode = AllDeviceInputAlwaysGoesToGameView 與 backgroundBehavior = IgnoreFocus（測試專用、結束還原，不影響實機）
