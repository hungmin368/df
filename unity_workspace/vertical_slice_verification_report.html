二、測試與建置明細

  • EditMode（13/13）：棋盤規則、連通區域、唯一解求解器、決定性生成器、回合計時與捕捉器規則、標記與逾時、saveVersion = 1 存檔往返、未來版本保護、八龍內容匯入。結果檔 TestResults/editmode.xml（13 passed / 0 failed / 0 skipped）。
  • PlayMode（8/8）：主選單 uGUI/TextMeshPro/InputSystem 堆疊、5×5 教學盤（25 格 + 焦點）、6×6 正式局（180 秒、9 捕捉器、36 格、可見焦點框）、選單鍵盤導覽、Enter 恰好單次觸發、方向鍵 + WASD 移動焦點、模擬觸控點擊標記，以及本次新增的 TutorialCompletesViaKeyboardAndPersistsSave——透過真實 InputSystemUIInputModule 鍵盤路徑完整通關教學（Space ×3 → C → Enter ×5），斷言回合為 Won、「教學完成」結果覆層出現，且磁碟存檔回讀為 tutorialCompleted = true（測試後還原現場存檔）。結果檔 TestResults/playmode.xml（8 passed / 0 failed / 0 skipped）。
  • Windows 建置：批次建置 exit code 0，日誌記錄 Windows build completed；Builds/Windows 含 DragonFinder.exe、UnityPlayer.dll、DragonFinder_Data、MonoBleedingEdge、D3D12；file 判定執行檔與 UnityPlayer.dll 皆為 PE32+ x86-64。

三、離機（離線）驗證

  • 所有 Assets/ 源碼以 UnityWebRequest|System.Net|Socket|HttpClient|WebClient|NetworkTransport 搜尋：零比對。
  • Packages/manifest.json 僅含 Input System、URP、Test Framework、uGUI 與 Unity 預設模組，無多人連線套件。
  • 主選單明示「離線遊玩・不收集資料」，與實際行為一致；Player.log 各次啟動皆無任何網路活動記錄。

四、存檔系統驗證

  • Windows 玩家寫入 + 正式版回讀（實機）：建立受 DF_TUTORIAL_VERIFY 編譯符號保護的獨立 Windows 驗證版，於實際 AppBootstrap 中依序執行教學的標記、切換捕捉與五次捕捉路徑；驗證版寫出 PASS，並在 %USERPROFILE%\AppData\LocalLow\Dragon Finder Studio\Dragon Finder\dragonfinder.save.json 寫入 saveVersion: 1、tutorialCompleted: true。隨後啟動未改動的正式 Builds/Windows/DragonFinder.exe，主選單顯示「教學：已完成」及「開始 6×6 正式探索」，完成實際玩家寫入→正式版回讀的端對端驗證。
  • 寫入路徑：新增 PlayMode 測試在真實場景以真實 UI 輸入完整通關教學，斷言 Application.persistentDataPath 下存檔寫入且回讀正確；EditMode 另覆蓋原子寫入、損壞檔保留、未來版本不被覆蓋。

實機截圖：讀取預置 saveVersion=1 存檔後的主選單（教學已完成、收集 2/8、勝場 2、進入 6×6 正式探索）。

五、輸入與無障礙回饋

  • 鍵盤：方向鍵/WASD 導覽、Enter/Space 操作、C/R/Esc/M 快捷鍵，全部走單一 EventSystem 路徑（無雙發缺陷，PlayMode 斷言）。
  • 滑鼠：標準 uGUI 指標路徑；觸控：與指標共用管线，PlayMode 以模擬觸控裝置點擊格位並斷言標記成功。
  • 可見焦點：目前格白色 Outline、教學目標格黃色 Outline（PlayMode 斷言 enabled 狀態）。
  • 區域字母：每格標示「區A–區F」，不以顏色作為唯一辨識。
  • UI 縮放：CanvasScaler ScaleWithScreenSize（1920×1080 基準）外加選單「介面大小」90%–110% 三段切換。
  • 聽覺/文字回饋：五種動作音效（可 M 切換並持久化）、每個操作皆有狀態列文字回饋、按鈕選取/高亮色分明。

七、環境限制說明

本機（Windows）對合成輸入注入設有防護：在已確認遊戲為前景視窗、選單已就緒、SendInput 回報成功的條件下，鍵盤事件仍無法到達任何程式（以全系統 Win+D 探測亦無反應）。因此「於建置版玩家內以腳本自動完整遊玩一局的互動式端對端」在本機無法自動化，屬環境限制而非遊戲缺陷。

補償驗證：輸入→流程→存檔寫入的完整鏈路改在 PlayMode 真實場景以引擎層輸入注入驗證（8/8 通過）；建置版玩家則以預置存檔驗證讀取鏈路並多次啟動確認日誌乾淨。真實使用者手動輸入不受此防護影響。
