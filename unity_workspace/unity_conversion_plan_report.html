Dragon Finder Unity 可玩垂直切片轉換計畫

已確認開工　日期：2026-09-24

目標

在 unity_workspace/DragonFinder 建立可於 Windows 10 64 位元以上執行的 Unity 垂直切片；Windows 版本成熟後才開始 iOS 適配。

已確認技術基線

項目決策
UnityUnity 6 LTS（實作版本 6000.3.24f1）與 URP 2D Renderer
UIuGUI + TextMeshPro，玩家文字使用繁體中文
Windowsx86_64、Windows 10 64 位元以上、免安裝資料夾版
畫面與輸入可縮放 16:9 視窗、中央直向內容；滑鼠與完整鍵盤操作，保留觸控介面
資料JSON 作為轉換中介，匯入後使用 ScriptableObject
存檔saveVersion=1 的本機 JSON；首版不匯入網頁存檔、不保存進行中棋盤
連線完全離線、零遙測、零崩潰回報服務

垂直切片內容

  1. 啟動畫面與主選單。
  2. 固定唯一解的 5×5 簡化教學。
  3. 6×6 正式局：180 秒、9 個捕捉器。
  4. 每行、每列、每區各一隻恐龍，恐龍八方向不得相鄰。
  5. 捕捉成功加 30 秒但不超過初始時間；最後一個捕捉器抓到最後一隻時判定勝利。
  6. 勝敗結算、重玩、回主選單與基本進度保存。
  7. 6–12 個具明確使用權或自製臨時替代的代表素材。
  8. 短音效與音效開關；暫不加入背景音樂。

首版不包含完整圖鑑、地圖、寶箱、經濟、技能、伙伴養成、龍塔、故事、網頁存檔匯入與中途續局。

架構

  • 純 C# Domain：棋盤、求解、生成、回合狀態與規則，不依賴 UnityEngine。
  • Unity 適配層：uGUI、輸入、存檔、音效與畫面控制。
  • Editor：JSON 匯入、ScriptableObject 生成、內容驗證與 Windows 批次建置。
  • 單一主場景：在同一 Canvas 內切換選單、教學、正式局與結算。

驗證方法

層級驗證通過條件
EditMode索引、鄰接、區域連通、規則、求解器、生成器、回合狀態、存檔與匯入資料所有自動測試通過；5×5 與 6×6 盤面合法且唯一解
PlayMode新存檔進教學、鍵盤完成教學、6×6 勝敗、重新啟動、音效設定完整流程可操作，沒有未處理例外或控制台錯誤
UI1280×720、1600×900、1920×1080；滑鼠和鍵盤內容置中無裁切；焦點可見；狀態不只靠顏色辨識
Windows Build批次建置 StandaloneWindows64 並啟動冒煙測試產出資料夾版，可進入並完成一局
離線斷網啟動與遊玩核心流程及存檔正常，沒有外部請求

完成條件

只有在自動測試、實際 UI 流程與 Windows 建置均通過後，才將本垂直切片標記完成；未經另行授權不提交、不推送、不發布。
