驗證發現並修正的缺陷

  1. 首次冒煙測試時，標記符號 U+2715（✕）在 StatusLabel 與 Label 共出現 4 次缺字警告，實際顯示為缺字方框。
  2. 以實際執行字型 Microsoft JhengHei UI 檢查：U+2715（✕）、U+2713、U+2717 皆無字符；U+00D7（×）、U+25C6（◆）、U+3000、U+2192、U+2605 皆有字符。
  3. 已將 UI 五處標記符號改為 U+00D7（×），並重新檢查介面原始碼使用到的 199 個字元，全部皆有字符。
  4. 修正後重跑 EditMode 10/10、PlayMode 3/3、重新建置並再次冒煙測試：缺字警告 0、例外 0。
