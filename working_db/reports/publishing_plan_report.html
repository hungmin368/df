⚡ 恐龍快找 DragonFinder — 上架平台評估報告

題目：如果想把遊戲上架，哪些平台合適？

結論：先走「零移植成本」的網頁平台（itch.io → CrazyGames → GitHub Pages/PWA），有數據後再談 Poki；原生商店只建議先做 Google Play；中國大陸渠道本階段不建議。

版本：v1.9.17　|　產出日期：2026-10-17　|　前份相關報告：appstore_publish_report.html（Google Play / App Store 準備清單，本報告不重複其 44 項細項，只做「平台選擇」決策）

一、一句話結論

最合適的路徑 本作是純靜態 HTML/CSS/JS、無建置步驟、總載入約 25MB、進度存 localStorage 的網頁遊戲， 所以「網頁遊戲平台」的移植成本是 0，而「原生商店」需要包裝、費用與審核，「中國小遊戲/安卓渠道」需要重寫渲染層＋版號資質。 因此優先順序是：itch.io（今天就可上）→ CrazyGames / GameDistribution（接 SDK 換流量）→ GitHub Pages 補 PWA（可安裝、也是 Play 上架前提）→ Google Play（US$25）； App Store 只在有 Mac 且願意為審核做原生化增強時才做；Steam、微信/抖音小遊戲、中國安卓商店本階段不建議。

二、現況盤點（決策依據的技術事實）

項目現況對上架的意義
技術棧單頁靜態網頁：index.html + css/ + js/，無任何相依套件、無建置步驟網頁平台可直接打包上傳；原生商店可用 WebView 包裝
UI 渲染方式DOM + CSS（非 canvas / WebGL），含影片、字型、CSS 動畫瀏覽器 iframe 與 WebView 都能跑；但微信/抖音小遊戲沒有 DOM，等於要重寫
實際出貨體積約 25MB：恐龍圖 4.7MB（139 張 webp）、地圖 3MB、字型 0.66MB、game.mp4 2.4MB、story_lv4_720p.mp4 13MB、JS/CSS 約 0.7MB遠低於所有平台的體積上限；但 13MB 劇情影片是首次載入時間的最大變數
存檔瀏覽器 localStorage（dinodoku-*），無伺服器、無帳號隱私政策容易寫（不蒐集個資）；但換裝置不同步，是商店評論的常見扣分點
目前发布狀態已上線 GitHub Pages：https://hungmin368.github.io/df/「已經有一个可公開遊玩的網址」= 所有網頁平台的投稿門檻都满足了
PWA 就緒度沒有 manifest.json、沒有 service worker目前手機不能「安裝到主畫面」；也是 TWA 方式上 Google Play 的前提
語言玩家介面只有繁體中文（另有 english_mode_assessment_report.html 評估過英文模式）繁中利基市場很精準；但 Poki / CrazyGames 的流量以歐美英語為主，沒有英文會明顯压低留存與分成收入
字型授權Huninn.woff2（jf open 粉圓）與 Iansui.woff2（粉圓）皆為 justfont 開源字型，可商用與重散布不是阻礙；但重散布時需在包內附上授權文字（OFL 類）
素材來源AI 生成（Gemini 圖像模型）+ 自行後製；详见 appstore_publish_report.html 的「素材來源盤點」各商店對 AI 生成素材的揭露要求不同，Google Play 與 Steam 都要求在表單中揭露

四、重點平台詳評

itch.io — 今天就該上，成本為零

自助上傳、不需 SDK、可設定「瀏覽器內直接遊玩」。把專案壓成 zip（只放 index.html、css/、js/、assets/ 中實際被引用的檔案，不要把 assets/dinos_2/ 那 461MB 素材工作區放進去）即可。

  • 價值：一個比 GitHub Pages 更像「產品頁」的公開網址，可放截圖、說明、更新日誌，並開啟留言收反馈。
  • 定價：可選免費 + 打賞，或自訂分成比例（含 0%）。繁中利基遊戲在這裡通常量不大，但零成本。
  • 注意：file:// 與跨域限制不同，上傳前用靜態伺服器完整跑一輪（影片、字型、恐龍圖、存檔）。

CrazyGames — 性價比最高的流量來源

接受 HTML5／JS 遊戲，流量在網頁遊戲平台中属第一梯隊。要吃到廣告分成就得接官方 SDK，並在程式中打出幾個事件：載入完成、請求廣告（關卡間）、gameplayStart / gameplayStop（讓它在遊玩中不要播廣告、並正確計時）。

  • 本作的接法：在關卡／塔關結算畫面之間插入「商業廣告」節點，是最自然的置入位置。
  • 審核看重的點：載入速度、可玩性、行動端操作。13MB 的 story_lv4_720p.mp4 建議改成延後載入或可略過，否則首次載入會被扣分。
  • 語言：平台流量以英語為主，沒有英文版會明顯压低平均遊玩時長，也就压低廣告收入。

Poki — 流量最大，但代價是合約

Poki 提供兩種合作型態：網頁獨家（web-exclusive，約 5 年合約）與非獨家，兩者都是收入分成，且必須整合 Poki SDK。

決策提醒 獨家條款會擋掉你自己網站與其他平台的收入。建議：先用 CrazyGames / GameDistribution 的非獨家渠道跑出真實數據（留存、平均遊玩時長）， 等手上有了數字，再評估 Poki 的獨家條件值不值得。不要在沒有數據時就簽長期獨家。

GitHub Pages + PWA — 你已經有的一半

目前缺三樣東西就能變成可安裝的 PWA：

  1. manifest.webmanifest（名稱、短名、display: standalone、主題色、各尺寸圖標 — 已有 app_icon.png 可切）
  2. Service worker（把 index.html、css/、js/、assets/dinos/、字型做成預快取離線包；兩段影片用「執行期快取」或干脆不快取）
  3. HTTPS（GitHub Pages 已具備）

好處是雙重的：手機用戶可以「安裝到主畫面」得到近似原生 App 的體驗；而且TWA（Trusted Web Activity）是上 Google Play 成本最低的路線，前提就是先有合格的 PWA。

Google Play — 原生商店裡唯一建議先做的

  • 費用只有 US$25 一次性，且 Android 的 WebView 對 DOM 遊戲支援良好，Capacitor 或 TWA 都能包裝。
  • 時程瓶頸是測試要求，不是技術：個人帳號需先建立封閉測試軌道，湊到 12 名測試者並持續 14 天，才能申請正式版。請把這 14 天排進時程，別以為打包完就能上。
  • 廣告：WebView 內不能放 AdSense，要接 AdMob（Capacitor 有官方插件）。
  • 文件：隱私政策網址（本作不蒐集個資，內容可以很短，但必須有）、內容分級問卷、AI 生成素材揭露。
  • 細項工作請照 appstore_publish_report.html 的 01–44 清單執行，本報告不重複。

Apple App Store — 建議晚一點，或先不做

最大風險：Guideline 4.2（最低功能性） 把靜態網頁用 Capacitor／WebView 套殼送上 App Store，被判定為「只是把網站包起來」而拒審的機率很高。 另外還需要 Mac + Xcode 才能簽章，以及 US$99／年。 若要上，先補：完整離線包、原生啟動畫面與圖標規範、至少一項「只有原生才有」的能力（例如原生通知、Game Center、或把 UI 改成原生導覽）。

五、不分平台都要先做的共同前置工作

1. 出货包瘦身只包實際被引用的檔案。assets/dinos_2/（461MB，含生成中間檔與 log）、js/*.bak*、tmp_*.mjs、各 *_report.html 一律排除。
2. 載入效能13MB 劇情影片延後載入或可略過；map.png（3MB）考慮切片或降解析；139 張恐龍圖改 lazy-load。
3. PWA 三件套manifest + service worker + 多尺寸圖標（192/512、maskable）。
4. 隱私政策 / 服務條款兩個公開網址。內容重點：無帳號、無伺服器、進度只存本機 localStorage、廣告由第三方平台 SDK 提供。
5. 授權文件字型（jf open 粉圓 / 粉圓）的 OFL 授權文字放進出貨包；AI 素材的生成與後製說明留檔，商店表單會問。
6. 商店素材圖標（512）、各平台尺寸截圖（手機 + 桌面）、一段 15–30 秒影片、簡短與完整描述。
7. 語言策略決定是否做英文介面。若目標是國際網頁平台，英文模式的優先級應該提高（已有 english_mode_assessment_report.html）。
8. 廣告節點設計先規劃「關卡間插頁廣告」的位置，這決定了 SDK 要插在哪幾行，也決定收入。

七、風險與注意事項

三個最容易踩的坑
  1. 把素材工作區一起出貨。assets/dinos_2/ 有 461MB（含生成中間檔、13MB 的 log、影片片段），一旦打包會讓上傳體積暴增 20 倍。出貨包只要約 25MB。
  2. 低估 Google Play 的 14 天。個人帳號的封閉測試要求是日曆時間，不是工時，排程時要提前兩週啟動。
  3. 太早簽 Poki 獨家。獨家會關掉自己網站與其他平台的收入；先拿非獨家渠道的數據，再談條件。
政策會變，上架前務必複查 本報告的費用與規則以 2026-10 查詢到的公開資料為準（Google Play 個人帳號 12 人 × 14 天、Microsoft Store 個人註冊免費、微信小遊戲 IAP 需版號 + 軟著）。 這些門檻各家常在調整，正式送審前請到各平台官方開發者文件再確認一次。
