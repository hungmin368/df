隨行羈絆自動排除驗證報告

尋龍高手 DragonFinder v1.9.13 ・ 日期：2026-10-13 ・ Task ID：buddy-auto-exclude

一、需求與變更

友好度 100% 的自動排除：僅捕獲恐龍時觸發 → 捕獲任一「隱藏物」都觸發（🦕 恐龍／🧰 寶箱／🪨 石頭）。

排除範圍維持原本口徑：同一橫列 ＋ 同一直欄 ＋ 周圍八格（含斜角）全部自動打 ✕。

實作方式：把原本內嵌在 doBall() 恐龍分支的滿好感區塊抽成共用函式 buddyAutoExclude(i, animMs)，命中解格後由三種類型共同呼叫。

觸發來源：捕捉器命中隱藏物，以及隨行技能「星願爆發」（reveal）揭示隱藏物——後者同樣會 G.found++，口徑上等同「捕獲到隱藏物」，故一併觸發（延遲 700ms）。

刻意未納入：開局關鍵寶箱格自動揭示（發生於渲染前、玩家尚未操作，開局就自動標記一片會造成困擾）、工程模式 dev-win（非玩家功能，直接結束該局）。

二、觸發條件與時序

條件行為
觸發來源① 捕捉器命中任一隱藏物（🦕／🧰／🪨）　② 隨行技能「星願爆發」揭示隱藏物
隨行寵物友好度 = 100%觸發自動排除；伴伴對話框提示「滿滿的羈絆！這行、這列和周圍我都幫你排除了 ✕」
友好度 < 100%完全不自動標記（僅原本的命中效果）
教學盤（4×4 示範／5×5 引導）不自動標記，避免干擾教學腳本
起始延遲 animMs恐龍 2200ms（五星 4200ms，等召喚動畫）；寶箱／石頭／星願爆發 700ms
逐格節奏每格間隔 200ms，玩家可隨時繼續操作
跳過的格子已標 ✕、已揭示、關鍵寶箱鎖定格（fixed）、以及任何尚未找到的隱藏物格（catUnion）

四、過程中發現並修正的缺陷：多解盤誤標

問題：N≥15 的盤面是「多解盤」——G.catUnion 存的是最多 4 組可行解的並集，所以同一列／同一欄／相鄰格可能各自還有另一個也算數的隱藏物。

實測 18×18：並集共 20 格，第 13 列與第 14 列各有 2 個隱藏物、第 10 欄與第 13 欄各有 2 個、另有 2 對相鄰。若照原邏輯整行整列標 ✕，會把「這裡沒有隱藏物」的 ✕ 打在還沒找到的隱藏物上，誤導玩家（此缺陷在舊版「僅恐龍觸發」時同樣存在）。

修正：自動排除的候選過濾 free() 加入 !catUnion.has(j)，任何尚未找到的隱藏物一律跳過；同時補上 !fixed，避免動到關鍵寶箱鎖定格（玩家本身也不可翻該格）。

驗證：18×18 捕捉 r17c10 恐龍 → 同行/同列/周圍 38 格中，2 格並集隱藏物（r17c16、r18c10）正確跳過，其餘 36 格全數標 ✕，被誤標的隱藏物 0 個。唯一解盤（≤14 與龍塔預生成盤）行為完全不變，因為那些盤面本來就不會有第二個隱藏物落在同行/同列/相鄰。

七、結論

  • 需求已實現：只要捕捉到隱藏物（恐龍／寶箱／石頭）且隨行寵物友好度達 100%，就會自動把同行、同列與周圍八格標 ✕；隨行技能「星願爆發」揭示隱藏物時亦同。
  • 安全性：唯一解盤上這些格子必然沒有隱藏物（每行/每列/每色區恰 1 個＋不相鄰），自動標記不會誤傷；多解盤已額外加入保護，不會把 ✕ 打在尚未找到的隱藏物上。
  • 時機：寶箱／石頭 700ms 後開始、恐龍等召喚動畫（2.2s／五星 4.2s）後開始，每格 200ms；18×18 大盤約 36 格需 8~9 秒跑完，期間不阻擋操作。

隨行閒聊進階秘訣驗證報告

尋龍高手 DragonFinder v1.9.14 ・ 日期：2026-10-13 ・ Task ID：buddy-tips-advanced

一、需求與結論

使用者提出 5 條「顏色計數／相鄰接觸」解謎秘訣，要求驗證正確性，修飾後加入隨行夥伴閒聊提示（BUDDY_TALK）。

結論：5 條全部正確 ✓，已修飾為「💡 進階：」格式加入 js/main.js 的 BUDDY_TALK 陣列（提示總數 67 → 72），於遊戲中由 pickTalk() 隨機抽用。

遊戲規則依據：每個顏色區塊、每行、每列各恰 1 個隱藏物（🦕 恐龍／🧰 寶箱／🪨 石頭），且隱藏物之間連斜角（八鄰接）都不得相鄰（玩法說明「高冷法則」、buddyAutoExclude 的排除邏輯）。

二、逐條驗證

原始秘訣判定推演依據
① N 排格子內部有 N+M 個顏色，N 顏色只在 N 排格子內，那麼多出的 M 顏色都可以清除 ✓ 正確 N 行恰有 N 個隱藏物；N 個不出行外的顏色各貢獻 1 個、全在行內，行內名額用滿 → 行內屬於其他 M 色的格子必無隱藏物。（精確說法：可 ✕ 的是「這 N 行內」屬於 M 色的格子）
② N 排格子內只有 N 個顏色，溢出 N 排格子同顏色的都可以清除 ✓ 正確 行內 N 個隱藏物顏色互異、只有 N 色可用 → 每色各 1 個都在這幾行 → 這些顏色行外的格子可 ✕。
③ 同顏色 2 連續格子，沒有其他格子同顏色，那同時接觸這 2 格子的周圍格子都可以清除 ✓ 正確 隱藏物必在其中一格 → 同時貼著（連斜角）這 2 格的格子，無論實際藏哪格都與之相鄰 → 可 ✕。（驗證中推廣：兩格不一定要相鄰也成立）
④ 同顏色的 L 形連續格子，盤面其他區域沒同顏色，可以找出 L 形包圍同時接觸的格子做清除 ✓ 正確 L 形 3 格必在 2×2 範圍內 → 同時貼著 3 格的格子＝2×2 的缺口格（唯一），無論藏哪格都相鄰 → 可 ✕。
⑤ 同顏色 3 連續格子成直線，盤面其他區域沒同顏色，可以找出相鄰同時接觸 3 連續格子做清除 ✓ 正確 直線 3 格 → 同時貼著 3 格的格子＝中間格兩側那 2 格（斜貼兩端、正貼中間）→ 可 ✕。

①②為「計數法」：祕訣①的「多出 M 顏色可清除」指其行內格子；③④⑤為「共同接觸法」：與所有可能藏匿位置同時相鄰的格子必可排除。①②對「列」同樣成立。

三、遊戲內最終文案（BUDDY_TALK）

  • 💡 進階：N 行裡若有 N 種顏色完全沒延伸到行外，這幾行剩下的格子都能打 ✕！（列也適用）
  • 💡 進階：N 行裡剛好只有 N 種顏色，這些顏色就各藏一個在這幾行——行外同色的格子都能打 ✕！（列也適用）
  • 💡 進階：一種顏色只剩 2 格——無論藏在哪格，同時貼著這 2 格的格子（連斜角）都能打 ✕！
  • 💡 進階：一種顏色是 L 形 3 格，同時貼著這 3 格的格子（L 的缺口）能打 ✕！
  • 💡 進階：一種顏色排成直線 3 格，同時貼著這 3 格的格子（中間格的兩側）能打 ✕！

文案沿用既有提示風格（💡 開頭、✕ 標記用語、結尾驚嘆號），並以「進階：」前綴與基礎提示區隔。
