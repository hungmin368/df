🦖 4×4 教學（示範模式）步驟報告

DragonFinder（尋龍高手）— 首次進入 4×4 關卡的自動示範教學，逐條詳列全部教學訊息與畫面動作

報告日期：2026-10-13　｜　原始碼：js/main.js 教學引擎（2493 行起）＋ index.html

一、概述

  • 觸發時機：玩家首次從主選單進入 4×4 關卡時（進度 PROG.tut4 未完成）自動啟動；教學標記完成後，之後再進 4×4 就是一般關卡。
  • 教學形式：「demo 示範模式」— 恐龍夥伴（對話框）全程自動示範一局，玩家純觀看，唯一可按的按鈕是「跳過教學 ▶▶」（示範模式中「繼續」按鈕不顯示）。
  • 盤面：4×4 盤面由 generatePuzzle(4, …, tutorial=true) 生成，仍是唯一解盤面：4 個顏色區塊各藏 1 隻恐龍，共 4 隻，且每列、每欄各 1 隻、恐龍互不相鄰（含斜角）。
  • 節奏：每個主步驟訊息間隔 2 秒（程式常數 D=2000），自動打 ✕ 時每格 0.24～0.5 秒。

一、需求與變更

第一次教學的 4×4 示範與 5×5 引導：每次隨機生成盤面 → 改用預生成的固定盤面，每位首次玩家所見完全相同。

實作方式：於 newBoard() 開頭新增分支——教學局且該尺寸有固定盤編碼時，以龍塔同款格式（每格一個 base-36 字元＝區域 id）towerDecode 解碼，經 solve2 驗證恰唯一解後交 finishBoard 生成；若固定盤資料缺損或非唯一解，自動退回原本隨機生成流程（防禦性回退）。

教學腳本本身（示範的自動推理旁白、引導的逐步互動）不需改動——兩者本就依盤面動態推理，固定盤上照常運作。

四、續行（同日）：秘訣教學流程

教學腳本改為遊戲秘訣驅動的完整循環：秘訣判斷可清除格 → 找出確定可捕捉格 → 捕捉後教可清除格 → 重複直到找出全部隱藏物。

  • 4×4 示範：移除「答案先偷偷告訴你」的作弊式揭示。改為——💡秘訣一「第 1、2 列含 3 色，A、B 兩色不延伸出這兩列 → C 色的 (1,0) 可 ✕」；💡秘訣二「B 色 L 形 3 格 → 共同接觸的 L 缺口 (0,2) 可 ✕」；尚無單格確定 → 挑最集中的 (0,1) 試捕（教「沒有確定格就先試最有把握的」）；捕後完整排除 → 其餘 3 隻全部「第 X 列只剩一個候選格 → 鐵定在這」確定鏈捕捉。
  • 5×5 引導：玩家親手操作秘訣——💡秘訣一「第 1 列整列皆 A → 行外 A 格 3 格」玩家點 ✕；💡秘訣二「E 色剩 2 格 → 同時貼著兩格的 2 格」玩家點 ✕；此時 A 色塊剩單格 →「百分百確定」捕捉首隻；捕後列／欄手動 ✕、斜角講解；其餘 4 隻確定鏈重複。
  • 捕捉後排除補全：示範的排除教學補上「周圍八格（連斜角）→ ✕」步驟（列 → 欄 → 八格 → 色塊），與玩法說明的高冷法則一致。
  • 教學瑕疵修正：引導循環原本「訊息說 A 格鐵定、發光卻是 B 格」可能不一致——改為捕捉推理實際證明的格子，訊息、發光、捕捉三者一致（實測捕捉順序 11 → 9 → 18 → 20，全部有推理依據）。
