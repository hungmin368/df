dragonfinder 根目錄結構說明

盤點日期：2026-10-22　｜　範圍：C:\MY_AI_JOBS\dragonfinder 根層的檔案與子目錄

總覽

根層目前有 8 個檔案與 7 個目錄。核心原則是：遊戲本體只放 game_db/，任務產物放 working_db/，其餘為治理文件、工具、平台專案與 Git／npm 產物。

dragonfinder/ ├─ game_db/ 遊戲本體（190 檔，唯一出貨來源） ├─ working_db/ 任務產物（749 MB，分類存放） ├─ tools/ 維護腳本（3 支） ├─ ios/ Capacitor iOS 原生專案 ├─ worklogs/ 未完成任務的工作紀錄 ├─ node_modules/ npm 依賴（不進版控） ├─ .git/ Git 版本庫資料 ├─ index.html GitHub Pages 導向頁 ├─ AGENTS.md 開發與協作規範 ├─ README.md 專案入口說明 ├─ CHANGELOG.md 版本更新日誌 ├─ .gitignore Git 忽略規則 ├─ capacitor.config.json Capacitor 設定 ├─ package.json npm 指令與依賴 └─ package-lock.json npm 依賴鎖定

根層目錄

目錄大小／檔案數用途
game_db/ 39 MB
190 檔		 遊戲唯一執行來源。包含 index.html、privacy.html、manifest、service worker、CSS、JS 與所有實際載入的素材。遊戲功能修改直接在此目錄進行。
working_db/ 749 MB
1,110 檔		 任務產物與開發素材，不直接出貨。依用途分為 reports、generated_assets、store、builds、docs、archive。新生成但游戏未使用的檔案先放這裡，經指示才移入 game_db/。
tools/ 16 KB
3 檔		 倉庫維護腳本：建置出貨包、產生 iOS 圖示／啟動畫面、拍攝 App Store 截圖。
ios/ 45 MB Capacitor iOS 原生專案（Xcode workspace、App 設定、SPM 套件與複製後的 web 資產）。npm run sync 會把 game_db/ 複製到 ios/App/App/public/。
worklogs/ 4 KB 任務工作紀錄。worklogs/ 只保留尚未完成的任務；任務完成後刪除其日誌，不保留 history/ 歸檔（歷史見 git commit log）。
node_modules/ 28 MB npm install 安裝的依賴（Capacitor、Playwright 等）。可重建、已被 gitignore，不屬於遊戲或報告內容。
.git/ 225 MB Git 版本庫本體（commit、分支、reflog、物件資料）。不可手動修改或刪除。

根層檔案

檔案用途
index.html GitHub Pages 入口頁，只負責把 /df/ 導向 /df/game_db/，並保留 query 與 hash。遊戲邏輯不在這裡。
AGENTS.md AI 協作與開發規範：目錄規則、game_db／working_db 分工、風格A 美術規範、寶箱美術、報告慣例、Git 流程與 worklog 規則。
README.md 專案入口說明：目錄結構、本機開啟方式、建置與 iOS 指令、開發慣例摘要。
CHANGELOG.md 版本更新日誌；目前含 v1.9.18 與本次目錄重構的 Unreleased 條目。
.gitignore 忽略建置輸出、備份、API 金鑰、生成管線中間檔、Python 快取與 node_modules/。
capacitor.config.json Capacitor 設定：appId、appName、webDir: "game_db"、iOS scheme 與背景色。
package.json npm 專案設定。build 執行 python tools/build_dist.py；sync 執行 npx cap sync ios。
package-lock.json 鎖定 npm 依賴版本，確保不同環境安裝結果一致。

tools/ 腳本

腳本用途
build_dist.py把 game_db/ 完整複製到 working_db/builds/dist/，並核對 index、CSS、JS、manifest 的執行期引用。
build_ios_icons.py從 working_db/generated_assets/icons/app_icon.png 產生 iOS AppIcon 與啟動畫面，輸出到同一分類目錄。
shoot_ios_screenshots.py用 Playwright 啟動 Chrome，對 /game_db/index.html 拍攝三種裝置的 App Store 截圖到 working_db/store/ios/screenshots/。

檔案流向與放置規則

遊戲要用的 → game_db/（維持內部相對路徑）。
任務生成、遊戲尚未使用 → working_db/generated_assets/ 對應分類。
報告 → working_db/reports/。
上架素材 → working_db/store/。
建置輸出 → working_db/builds/。
只有使用者明確指示「放進遊戲」時，才把檔案從 working_db/ 移到 game_db/。

不需要進版控的項目

  • node_modules/：可由 npm install 重建。
  • working_db/builds/dist/：可由 python tools/build_dist.py 重建。
  • working_db/generated_assets/**/_raw/、_master/、API 金鑰、剪輯中間檔與 Python 快取：已在 .gitignore 排除。
  • .git/：版本庫資料，不可刪除。
