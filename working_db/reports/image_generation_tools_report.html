🦖 圖像生成 MCP 工具調查報告

2026-10-15任務 ID：image-gen-mcp-search

目標：找到可加入 AI 助手工具組的圖像生成 MCP 伺服器，用於批量製作「伴伴風格」恐龍遊戲圖（139 張 200×200 WebP）。

⚡ 結論速覽

  • 本機 GPU 只有 MX550（2 GB），跑不動 FLUX / SDXL 本機生成 → 本機 ComfyUI / Stable Diffusion MCP 路線排除。
  • 首選：Gemini nano banana 系列 MCP（Junhan2/gemini-nanobanana-mcp 或多後端的 shinpr/mcp-image）——獨有參考圖風格一致性能力，可拿現有伴伴樣本當風格錨點，直接解決 v4「顏色不穩、物種辨識度不足」兩大痛點。
  • 次選：fal.ai 官方 MCP——OAuth 免設定 API key（https://mcp.fal.ai/mcp-relay），FLUX 生態，按量計費。
  • ⚠️ 注意：Gemini API 免費層不含圖像模型（官方定價頁），圖像生成為付費 $0.0336–$0.15/張；139 張約 $4.7–$21 美金。
  • 現有 pollinations/flux 免費管線仍可並行使用，作為零成本備援。

三、重點工具詳解

🥇 gemini-nanobanana-mcp

★★★★★首選
  • 來源：github.com/Junhan2/gemini-nanobanana-mcp（同類型另有 shinpr/mcp-image 多後端版）
  • 能力：文字生圖、圖片編輯、多圖合成、風格轉換（吃參考圖）；環境變數 GEMINI_API_KEY、AUTO_SAVE 等。
  • key 取得：Google AI Studio 免費申請（API key 本身免費）。
  • 為什麼最適合伴伴恐龍：v4 的兩大痛點是「flux 對指定顏色不聽話」與「物種特徵被淹沒」。nano banana 可以直接拿已核准的 4 張伴伴樣本當參考圖要求「照這個風格畫一隻劍龍」，風格錨定能力遠高於純文字 prompt。
⚠️ 官方定價頁確認：免費層不含圖像模型，圖像生成需綁定付費帳號，$0.0336–$0.15/張。請先在 AI Studio 確認你的帳號額度後再批量生成。

🥈 fal.ai 官方 MCP

★★★★☆最易接入
  • 來源：fal.ai 官方文件
  • 接入方式：MCP 位址 https://mcp.fal.ai/mcp-relay，OAuth 瀏覽器授權即可，不用設定 API key——四個候選中接入成本最低。
  • 能力：search_models（搜尋目錄模型）+ run_model（執行），支援 flux/dev 等生圖模型。
  • 費用：連線免費，每次模型呼叫扣 credits（需儲值）。
  • 注意：走 FLUX 文字生圖，風格錨定仍靠 prompt（可用 fal 上的 image-to-image / IP-Adapter 類模型補強）。

🥉 Image-Generation-MCP-Server（Replicate FLUX）

★★★☆☆
  • 來源：github.com/GongRzhe/Image-Generation-MCP-Server
  • 能力：單一 generate_image 工具，後端 Replicate FLUX；環境變數 REPLICATE_API_TOKEN。
  • 優勢：專案既有 _gen_v4.py 的 prompt 資產（解剖學排序、切圖色域把關）可直接沿用；FLUX schnell 檔次每張成本極低。
  • 劣勢：與 pollinations 免費管線同為 FLUX 文字生圖，解決不了現有的色彩/辨識度不穩問題，只是多了限流餘裕。

4. openai-gpt-image-mcp

★★★☆☆
  • 來源：github.com/SureScaleAI/openai-gpt-image-mcp
  • 能力：create-image / edit-image；gpt-image 系列以 prompt 遵循度最高著稱，指定顏色/構圖最聽話。
  • 費用：約 $0.03–0.19/張（依品質檔位），139 張約 $4–26。
  • 定位：若 nano banana 參考圖路線仍不穩，gpt-image 的「指令服從」是第二道保險。

建議的生成流程（接入 MCP 後）

  • 1️⃣ 用已核准的 v4 四張樣本（紫三角龍・綠劍龍・橘霸王龍・藍無齒翼龍）作為風格參考圖。
  • 2️⃣ 逐物種生成：prompt 維持「物種輪廓特徵優先、伴伴材質詞放最後」的既得經驗。
  • 3️⃣ 沿用既有後處理管線：rembg 去背 → 裁切置中 → 512 主檔 → 200×200 WebP。
  • 4️⃣ 保留色域把關腳本做自動驗收（每物種色帶檢查）。

  2. 在 SophCode 的 MCP / 工具設定中新增該 MCP 伺服器（以下為社群通用 JSON 格式，實際欄位位置以 SophCode 設定介面為準）：

  2. 批量前先算成本：139 張 × $0.034 ≈ $4.7 美金（最低檔），建議分批（每批 10–20 張）驗收。
💡 過渡方案：不裝 MCP 也可以——我現在就能用 Bash 呼叫 Gemini / fal / Replicate 的 REST API（就像先前的 _gen_leonardo.py）。MCP 的價值是把工具「常駐化」，之後每次對話都能直接用。

二、各工具特色詳述

1. pollinations.ai 現在就能用

  • 特色：免費、無需金鑰的純 GET 圖片端點（image.pollinations.ai/prompt/<提示>），支援 seed、模型參數；品質中上。
  • 本次實測：flux 模型 256×256 測試圖 2.7 秒成功回傳（HTTP 200）。
  • 已知缺點：免費層頻繁 402 速率限制（前次批量曾每 seed 都要重試）；顏色與解剖結構控制弱——前四轮已為此建了紫色色相閘門（hue gate）與候選重抽機制；/models 端點回傳不可靠（本次僅回 sana，但 flux 實測仍可用）。
  • 適合：樣品試做與免費保底，正式批量需搭配自動化篩選。

2. Gemini 圖像模型（nano-banana 家族） 金鑰有效，差開通計費

  • 特色：參考圖生圖（image-to-image with style reference）能力全場最強——餵一張伴伴渲染圖當錨點，一次性鎖定「紫色身體、金色大眼、黃橘色角、乳白腹部、粉紅翼膜」的家族特徵，再逐種替換物種與配色。對「139 張同風格不同物種」這種需求是目前業界公認的最佳解。
  • 可用模型（本次以金鑰實測 models 列表 HTTP 200）：gemini-2.5-flash-image、gemini-3-pro-image(-preview)、gemini-3.1-flash-image(-preview)、gemini-3.1-flash-lite-image 等 6 個圖像模型。
  • 阻擋點：此 Google 帳號免費層的圖像生成額度上限為 0（8 個模型全部 429，屬帳號級付費牆，非暫時性限流）；文字模型免費可用。只需在 Google Cloud 專案開通 pay-as-you-go 計費即可解鎖。
  • 費用：約 US$0.03–0.14／張依模型；139 張約 US$4–19。
  • 就緒度：測試腳本 assets/dinos_2/bban_samples/_gen_gemini_test.py 已寫好（以 v4 暴龍 512 大圖當參考），金鑰存於本機未追蹤檔案，開通計費後一鍵可跑。

3. Leonardo.Ai 瀏覽器仍登出；API 方案待購

  • 特色：Phoenix／Kino XL／Vision XL 等自家模型，照片級品質；Image Guidance 參考圖模式可餵伴伴圖鎖風格；Alchemy 高清放大；元素（Elements）可疊加風格 LoRA。
  • 兩條啟用路徑：(a) 購買 API Access 方案取得金鑰 → 批次全自動（腳本 _gen_leonardo.py 與 4 物種提示詞 _leonardo_prompts.md 已備好）；(b) 在本受控瀏覽器登入 app.leonardo.ai，我直接操作網頁 UI 產圖（本次實測仍跳轉登入頁，你的登入在另一個瀏覽器，我這邊看不到）。
  • 費用：App 訂閱約 US$12／月起；API 需額外 API 方案。

4. OpenAI Images API（gpt-image-1／DALL·E 3） 待提供金鑰

  • 特色：提示詞遵循最穩定、構圖最聽話；gpt-image-1 支援傳入參考圖做圖生圖編輯（維持構圖換配色、局部重繪），也有透明背景輸出參數——對「同一恐龍多配色版本」特別有用。
  • 費用：gpt-image-1 低／中／高品質約 US$0.02／0.07／0.19 每張；DALL·E 3 約 US$0.04–0.08。
  • 啟用：提供 OPENAI_API_KEY 即可，我可以現場寫批次腳本。

5. fal.ai／Replicate（模型聚合平台） 待註冊 token

  • 特色：一支 token 調用數百個模型——flux-pro／flux-dev／flux-schnell、SD 系列、各家微調版；REST 介面統一，按次計費不訂閱。想要 flux 最高品質又不想在本機裝 ComfyUI 時最省事。
  • 費用：flux-schnell 接近免費級，flux-pro 約 US$0.05／張。

6. Stability AI 待金鑰

  • 特色：SD 3.5 Large／Turbo 官方 API；steps／cfg 等參數全開放可調，商用授權條款清晰；適合想細調參數的人。
  • 費用：credit 制，約 US$0.06／張。

7. Ideogram 待金鑰

  • 特色：圖片內文字渲染業界最強（海報、LOGO、卡牌設計級）；對恐龍生成非必需，未來遊戲宣傳圖可考慮。

8. Midjourney 無官方 API，不建議

  • 特色：美感與材質表現公認最強。
  • 但：沒有官方 API，只能靠受控瀏覽器登入其網頁或 Discord 操作；批次 139 張的自動化脆弱、容易被驗證碼擋（本次 Leonardo 登入頁已見 Cloudflare 驗證）。不建議用於正式批量。

9. 本機 ComfyUI＋開源模型 本機未安裝

  • 特色：完全免費、無張數限制、資料不出機、可寫 workflow 一鍵批量 139 張；flux-dev／SD3.5 品質接近付費前端。
  • 代價：需要夠力的獨立顯卡（flux-dev 建議 12GB+ VRAM），模型檔 12–25GB；本機已查過 7860／8188 埠無本地生圖服務，需從零安裝。若不確定顯卡型號，我可以幫你查。

  1. 首選：Gemini 開通計費——你已有的金鑰只差這一步；參考圖能力對「伴伴家族一致性」幫助最大，開通後立刻可跑現成測試腳本驗證一張（約 US$0.03）。

  3. 第三：OpenAI gpt-image-1 或 fal.ai——提供金鑰即可上線，前者圖生圖編輯強、後者 flux 品質高且按次計費。
  4. 保底：pollinations.ai——免費且現在就能跑（本次已實測），搭配既有的色相閘門管線先出樣品給你審風格。
  5. 長遠：本機 ComfyUI——若這台机器有合格顯卡，139 張批量長期最省。
