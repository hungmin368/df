一、現況盤點（已完成的優勢）

依據對目前程式碼的實際調查，這個專案對上架而言起點非常好：

✅ 完全離線全專案零外部連結、零 fetch。WebView 包裝後不需任何網路權限，商店可申報「不收集任何資料」，隱私審核阻力最小。
✅ 已有單檔整合包build_single_file.mjs 已能把整個遊戲（含 139 張圖、字型、音效邏輯）包成一個 25 MB HTML，正是塞進 App 的理想形態。
✅ 無版權音檔音效全部用 Web Audio API 即時合成（無 .mp3/.wav），沒有音樂授權問題。
✅ 無實質 Pokémon 內容程式變數已更名為 DINOS（原 POKEMON），內容全是真實恐龍的中文名（梁龍、三角龍、霸王龍…），無任天堂素材。
✅ 開源字型內嵌字型 jf open 粉圓（Huninn）、芫荽（Iansui）皆採 SIL OFL 授權，可合法嵌入 App，僅需標示來源。

❌ 仍待確認：139 張 assets/dinos/*.webp 恐龍圖、assets/cursor.png 游標、16 張 assets/story/s*.svg 故事圖（自繪？AI 生成？網路下載？）。若是他人作品且無授權，兩大商店都會因檢舉下架，且有侵權責任。這是唯一我無法替你確認的事。
📝 Copilot 生成圖像的商用依據（2026-09-24 查證）
① 現行《Microsoft Copilot 補充使用條款》明訂「我們不擁有你的內容（Your Content）」，生成圖像權利在你，使用須遵守其行為準則；但 Microsoft 對 Copilot 生成內容不提供任何擔保。
② 歷史沿革：2023 年 Bing Image Creator 條款曾限定「個人非商業用途」；2024 年條款改版後該限制已移除，但 Microsoft 未發布正式商用聲明，社群解讀仍有分歧。
③ 實務建議：上架前留存當下條款快照與你的生成紀錄（prompt、日期、對話截圖）作為佐證；如需更高確定性，可訂閱 Copilot Pro 並向 Microsoft 支援取得確認。
參考：Copilot Supplemental Terms of Use・Microsoft Q&A：圖像商用討論
R2｜Google 新個人帳號封測政策
2023 年 11 月之後註冊的「個人」開發者帳號，正式上架前須先完成封閉測試：至少 20 名測試員、連續 14 天。組織帳號不受此限（但需要 D-U-N-S 碼與組織驗證）。這是 Android 上架最大的流程門檻，實際以 Play Console 當下規定為準。
R3｜iOS 必須有 Mac
iOS 的建置與上傳（Xcode Archive）只能在 macOS 上進行。本機是 Windows，我無法在此完成 iOS build。替代方案：租用雲端建置（如 Codemagic），但 Apple 開發者帳號綁定與上傳憑證仍須你操作。
R4｜Android 簽署金鑰（keystore）遺失＝無法更新
keystore 一旦遺失，該 App 永遠無法再發新版本（只能下架重發、玩家失去存檔）。金鑰實體與密碼必須由你保管，不可交給任何人（包括我）。
R5｜「家庭自用」聲明與公開發行矛盾
目前 footer 寫「本遊戲不販賣、不公開，家庭自用，請勿盜用」，公開上架後這句話必須修改，否則觀感矛盾（文字修改我可做，見流水號 08）。
R6｜兒童向 App 審核更嚴
本遊戲明顯適合兒童。若商店認定為兒童向，Google Families 政策與 Apple 兒童類別會加嚴審查（不得有廣告、外部連結、資料收集）。本 App 離線無收集，技術上符合，但問卷要填對。
R7｜公開 repo 內的寶可夢球備份檔（2026-09-24 盤點時發現）
assets/cursor_pokeball.bak.png 經目視確認為像素風寶可夢球（Pokémon 系列代表性圖示）。它未被遊戲引用，但已提交到公開 GitHub repo，可經 GitHub Pages 直接存取。建議：以一個新 commit 將該檔自 repo 移除（不影響遊戲運作），讓它從網站與最新版本消失；注意 git 歷史仍會保留該檔，而本 repo 規則禁止改寫已發布歷史，是否進一步處理由你決策。商店審核不會掃描 repo，但這是現行且公開的任天堂 IP 暴露，建議越早處理越好（要動工時說一聲，我來做移除 commit）。
