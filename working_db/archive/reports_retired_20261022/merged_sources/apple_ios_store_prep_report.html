五、你在 Mac 上的最後一段路（工程已全部備妥）

# 1) 取得最新程式碼
git clone https://github.com/hungmin368/df.git
cd df

# 2) 安裝依賴並重建離線包＋同步進 iOS 工程
npm install
npm run sync        # = python build_dist.py + npx cap sync ios

# 3) 打開 Xcode 工程（Swift Package 依賴會自動解析，不需 CocoaPods）
open ios/App/App.xcodeproj

# 4) Xcode 內：
#    - 選 App target → Signing & Capabilities → Team 選你的 Apple ID
#    - 版本號更新：MARKETING_VERSION（1.9.17 → 新版）、CURRENT_PROJECT_VERSION +1
#    - 頂端裝置選「Any iOS Device (arm64)」→ Product > Archive
#    - Archive 完成後 Distribute App → App Store Connect → Upload

# 5) 回 App Store Connect 網頁：填第二節草稿、傳截圖、勾第三節隱私標籤 → 送審
Guideline 4.2（最低功能要求）對沖現況：目前已具備「完整離線包＋原生觸覺回饋＋自訂圖標與啟動畫面」。若審核仍質疑「只是網頁套殼」，下一步可加：App 圖示的 3D Touch/長按捷徑、每日推播通知（@capacitor/local-notifications）、或 Game Center 排行榜——需要的話跟我說，我就能先做好。
