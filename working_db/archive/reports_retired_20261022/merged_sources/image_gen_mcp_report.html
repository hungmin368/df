🦖 圖像生成 MCP 工具調查報告

2026-10-15任務 ID：image-gen-mcp-search

目標：找到可加入 AI 助手工具組的圖像生成 MCP 伺服器，用於批量製作「伴伴風格」恐龍遊戲圖（139 張 200×200 WebP）。

⚡ 結論速覽

  • 本機 GPU 只有 MX550（2 GB），跑不動 FLUX / SDXL 本機生成 → 本機 ComfyUI / Stable Diffusion MCP 路線排除。
  • 首選：Gemini nano banana 系列 MCP（Junhan2/gemini-nanobanana-mcp 或多後端的 shinpr/mcp-image）——獨有參考圖風格一致性能力，可拿現有伴伴樣本當風格錨點，直接解決 v4「顏色不穩、物種辨識度不足」兩大痛點。
  • 次選：fal.ai 官方 MCP——OAuth 免設定 API key（https://mcp.fal.ai/mcp-relay），FLUX 生態，按量計費。
  • ⚠️ 注意：Gemini API 免費層不含圖像模型（官方定價頁），圖像生成為付費 $0.0336–$0.15/張；139 張約 $4.7–$21 美金。
  • 現有 pollinations/flux 免費管線仍可並行使用，作為零成本備援。

三、重點工具詳解

🥇 gemini-nanobanana-mcp

★★★★★首選
  • 來源：github.com/Junhan2/gemini-nanobanana-mcp（同類型另有 shinpr/mcp-image 多後端版）
  • 能力：文字生圖、圖片編輯、多圖合成、風格轉換（吃參考圖）；環境變數 GEMINI_API_KEY、AUTO_SAVE 等。
  • key 取得：Google AI Studio 免費申請（API key 本身免費）。
  • 為什麼最適合伴伴恐龍：v4 的兩大痛點是「flux 對指定顏色不聽話」與「物種特徵被淹沒」。nano banana 可以直接拿已核准的 4 張伴伴樣本當參考圖要求「照這個風格畫一隻劍龍」，風格錨定能力遠高於純文字 prompt。
⚠️ 官方定價頁確認：免費層不含圖像模型，圖像生成需綁定付費帳號，$0.0336–$0.15/張。請先在 AI Studio 確認你的帳號額度後再批量生成。

🥈 fal.ai 官方 MCP

★★★★☆最易接入
  • 來源：fal.ai 官方文件
  • 接入方式：MCP 位址 https://mcp.fal.ai/mcp-relay，OAuth 瀏覽器授權即可，不用設定 API key——四個候選中接入成本最低。
  • 能力：search_models（搜尋目錄模型）+ run_model（執行），支援 flux/dev 等生圖模型。
  • 費用：連線免費，每次模型呼叫扣 credits（需儲值）。
  • 注意：走 FLUX 文字生圖，風格錨定仍靠 prompt（可用 fal 上的 image-to-image / IP-Adapter 類模型補強）。

🥉 Image-Generation-MCP-Server（Replicate FLUX）

★★★☆☆
  • 來源：github.com/GongRzhe/Image-Generation-MCP-Server
  • 能力：單一 generate_image 工具，後端 Replicate FLUX；環境變數 REPLICATE_API_TOKEN。
  • 優勢：專案既有 _gen_v4.py 的 prompt 資產（解剖學排序、切圖色域把關）可直接沿用；FLUX schnell 檔次每張成本極低。
  • 劣勢：與 pollinations 免費管線同為 FLUX 文字生圖，解決不了現有的色彩/辨識度不穩問題，只是多了限流餘裕。

4. openai-gpt-image-mcp

★★★☆☆
  • 來源：github.com/SureScaleAI/openai-gpt-image-mcp
  • 能力：create-image / edit-image；gpt-image 系列以 prompt 遵循度最高著稱，指定顏色/構圖最聽話。
  • 費用：約 $0.03–0.19/張（依品質檔位），139 張約 $4–26。
  • 定位：若 nano banana 參考圖路線仍不穩，gpt-image 的「指令服從」是第二道保險。

四、對「伴伴風格恐龍」的適配分析

現有管線的痛點（來自 worklog_bban-style-dinos Rounds 2–7）

痛點現況哪個 MCP 能解
指定體色不聽話（紫/綠/橘/藍常跑色）flux 需要 seed 重試 + 色域把關腳本nano banana 參考圖錨定、gpt-image 指令服從
物種辨識度（三角龍頭盾、劍龍骨板）常丟失v3→v4d 跑了 7 輪才定案 4 張nano banana：拿核准樣本當參考圖直接編輯
免費 API 限流（HTTP 402）拖慢批量每個 seed 首次請求幾乎必 402付費 API（fal / Replicate / Gemini / OpenAI）皆有穩定配額
139 張批量的一致性每張獨立 seed，風格漂移nano banana 參考圖是唯一能「家族化」的方案

建議的生成流程（接入 MCP 後）

  • 1️⃣ 用已核准的 v4 四張樣本（紫三角龍・綠劍龍・橘霸王龍・藍無齒翼龍）作為風格參考圖。
  • 2️⃣ 逐物種生成：prompt 維持「物種輪廓特徵優先、伴伴材質詞放最後」的既得經驗。
  • 3️⃣ 沿用既有後處理管線：rembg 去背 → 裁切置中 → 512 主檔 → 200×200 WebP。
  • 4️⃣ 保留色域把關腳本做自動驗收（每物種色帶檢查）。

五、接入步驟建議

  1. 申請 Google AI Studio API key（或 fal.ai 帳號走 OAuth）。
  2. 在 SophCode 的 MCP / 工具設定中新增該 MCP 伺服器（以下為社群通用 JSON 格式，實際欄位位置以 SophCode 設定介面為準）：
{
  "mcpServers": {
    "gemini-nanobanana": {
      "command": "npx",
      "args": ["-y", "github:Junhan2/gemini-nanobanana-mcp"],
      "env": { "GEMINI_API_KEY": "你的_AI_STUDIO_KEY" }
    }
  }
}
  1. 重啟對話後，我會看到新的生成工具；先以 4 張樣本當參考圖試生成 1 張驗證風格，再談批量。
  2. 批量前先算成本：139 張 × $0.034 ≈ $4.7 美金（最低檔），建議分批（每批 10–20 張）驗收。
💡 過渡方案：不裝 MCP 也可以——我現在就能用 Bash 呼叫 Gemini / fal / Replicate 的 REST API（就像先前的 _gen_leonardo.py）。MCP 的價值是把工具「常駐化」，之後每次對話都能直接用。
