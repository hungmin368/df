③ 批量替換需保留要素（核心結論）

  • 檔案規格：200×200 RGBA 透明 WebP（品質約 90、6–21 KB），檔名維持 assets/dinos/<id>.webp 與 id 1:1 對應 → js/data.js 零改動、存檔免遷移
  • 物種對應：每個 id 的物種不可錯置——新圖必須就是該 id 的那一隻（名字見 data.js）
  • 構圖：單一主體、置中、底部貼齊（下緣 4–5% 邊距）、四周 ≥4% 邊距、全身含尾巴不裁切、覆蓋率抓 20–40%
  • 姿勢一致：全 139 張統一正面／微 3/4 站姿面向鏡頭（現行慣例），不可混入側面全身或飛行姿
  • 5★ 金冠＋龍翼：傳說標記必須保留；1★–4★ 維持無冠（星級一眼可辨）
  • 剪影差異化：每種的招牌剪影（長頸、盾角、骨板、背帆、鐮爪、翼…）要在輪廓上讀得出來——剪影猜謎玩法依賴這個
  • 專屬體色：每物種一個鮮明主色（風格A既有規則），且轉灰階後形體仍可辨識
  • 乾淨去背：純白底 → 完全透明、無白邊光暈、無陰影烙印、無浮水印文字
  • 範圍界線：只動 assets/dinos/ 139 張；伴伴吉祥物 7 張（1–5星/win/fail）、game_logo、故事圖、游標一概不動
