二、各工具特色詳述

1. pollinations.ai 現在就能用

  • 特色：免費、無需金鑰的純 GET 圖片端點（image.pollinations.ai/prompt/<提示>），支援 seed、模型參數；品質中上。
  • 本次實測：flux 模型 256×256 測試圖 2.7 秒成功回傳（HTTP 200）。
  • 已知缺點：免費層頻繁 402 速率限制（前次批量曾每 seed 都要重試）；顏色與解剖結構控制弱——前四轮已為此建了紫色色相閘門（hue gate）與候選重抽機制；/models 端點回傳不可靠（本次僅回 sana，但 flux 實測仍可用）。
  • 適合：樣品試做與免費保底，正式批量需搭配自動化篩選。

2. Gemini 圖像模型（nano-banana 家族） 金鑰有效，差開通計費

  • 特色：參考圖生圖（image-to-image with style reference）能力全場最強——餵一張伴伴渲染圖當錨點，一次性鎖定「紫色身體、金色大眼、黃橘色角、乳白腹部、粉紅翼膜」的家族特徵，再逐種替換物種與配色。對「139 張同風格不同物種」這種需求是目前業界公認的最佳解。
  • 可用模型（本次以金鑰實測 models 列表 HTTP 200）：gemini-2.5-flash-image、gemini-3-pro-image(-preview)、gemini-3.1-flash-image(-preview)、gemini-3.1-flash-lite-image 等 6 個圖像模型。
  • 阻擋點：此 Google 帳號免費層的圖像生成額度上限為 0（8 個模型全部 429，屬帳號級付費牆，非暫時性限流）；文字模型免費可用。只需在 Google Cloud 專案開通 pay-as-you-go 計費即可解鎖。
  • 費用：約 US$0.03–0.14／張依模型；139 張約 US$4–19。
  • 就緒度：測試腳本 assets/dinos_2/bban_samples/_gen_gemini_test.py 已寫好（以 v4 暴龍 512 大圖當參考），金鑰存於本機未追蹤檔案，開通計費後一鍵可跑。

3. Leonardo.Ai 瀏覽器仍登出；API 方案待購

  • 特色：Phoenix／Kino XL／Vision XL 等自家模型，照片級品質；Image Guidance 參考圖模式可餵伴伴圖鎖風格；Alchemy 高清放大；元素（Elements）可疊加風格 LoRA。
  • 兩條啟用路徑：(a) 購買 API Access 方案取得金鑰 → 批次全自動（腳本 _gen_leonardo.py 與 4 物種提示詞 _leonardo_prompts.md 已備好）；(b) 在本受控瀏覽器登入 app.leonardo.ai，我直接操作網頁 UI 產圖（本次實測仍跳轉登入頁，你的登入在另一個瀏覽器，我這邊看不到）。
  • 費用：App 訂閱約 US$12／月起；API 需額外 API 方案。

4. OpenAI Images API（gpt-image-1／DALL·E 3） 待提供金鑰

  • 特色：提示詞遵循最穩定、構圖最聽話；gpt-image-1 支援傳入參考圖做圖生圖編輯（維持構圖換配色、局部重繪），也有透明背景輸出參數——對「同一恐龍多配色版本」特別有用。
  • 費用：gpt-image-1 低／中／高品質約 US$0.02／0.07／0.19 每張；DALL·E 3 約 US$0.04–0.08。
  • 啟用：提供 OPENAI_API_KEY 即可，我可以現場寫批次腳本。

5. fal.ai／Replicate（模型聚合平台） 待註冊 token

  • 特色：一支 token 調用數百個模型——flux-pro／flux-dev／flux-schnell、SD 系列、各家微調版；REST 介面統一，按次計費不訂閱。想要 flux 最高品質又不想在本機裝 ComfyUI 時最省事。
  • 費用：flux-schnell 接近免費級，flux-pro 約 US$0.05／張。

6. Stability AI 待金鑰

  • 特色：SD 3.5 Large／Turbo 官方 API；steps／cfg 等參數全開放可調，商用授權條款清晰；適合想細調參數的人。
  • 費用：credit 制，約 US$0.06／張。

7. Ideogram 待金鑰

  • 特色：圖片內文字渲染業界最強（海報、LOGO、卡牌設計級）；對恐龍生成非必需，未來遊戲宣傳圖可考慮。

8. Midjourney 無官方 API，不建議

  • 特色：美感與材質表現公認最強。
  • 但：沒有官方 API，只能靠受控瀏覽器登入其網頁或 Discord 操作；批次 139 張的自動化脆弱、容易被驗證碼擋（本次 Leonardo 登入頁已見 Cloudflare 驗證）。不建議用於正式批量。

9. 本機 ComfyUI＋開源模型 本機未安裝

  • 代價：需要夠力的獨立顯卡（flux-dev 建議 12GB+ VRAM），模型檔 12–25GB；本機已查過 7860／8188 埠無本地生圖服務，需從零安裝。若不確定顯卡型號，我可以幫你查。
